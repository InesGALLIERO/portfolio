Description

Contexte : Ce projet consiste à développer un backend sécurisé pour une application de gestion de livres, avec stockage de données conforme et structuré

Objectifs : Mettre en place un serveur Node.js capable de gérer une API REST avec authentification et opérations CRUD sécurisées.

Stack technique : Node.js, Express, MongoDB, Mongoose, authentification JWT, GitHub.

Compétences développées : J’ai appris à modéliser une base de données, sécuriser des routes et implémenter des opérations CRUD tout en respectant les bonnes pratiques backend.

Résultats et impact : L’API permet une gestion complète des données avec authentification utilisateur et stockage sécurisé dans MongoDB.

Perspectives d'amélioration : Ajouter des tests automatisés, renforcer la sécurité (validation avancée, rate limiting) et améliorer la gestion des erreurs.
